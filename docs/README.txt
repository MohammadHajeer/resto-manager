RestoManager KfW Product Demo

Launch:
1. Keep this entire product-demo folder together.
2. In PowerPoint, link BEGIN LIVE DEMO to index.html.
3. Open index.html in a modern browser.
4. Press Start Demo when the presenter is ready.

Controls:
- Right Arrow or Space: next scene
- Left Arrow: previous scene
- On-screen arrow buttons are also available

Offline readiness:
- All screenshots, CSS, JavaScript, logo, and font files are local.
- The demo does not require RestoManager, its API, a development server, or internet access.

Presenter flow:
Auth → Admin → Owner → Customer → Complete
